## Priority gates

**P0 — Before any live client action:** verified source, suppression check, clear buyer requirement, permission, safe budget and ownership.

**P0 — Before any real CRM website integration:** authenticated backend, read-only validation, audit trail and protected tokens.

**P1 — Before any paid pilot:** client-owned permissions, representative test files, source-output verification, exception routing, defined acceptance criteria and written scope.

**P2 — Once a client is won:** monitored rollout, backups, support ownership, handover, verified payment and case-study consent.
